正常 Coding 修复由真实模型读取源码、提交文件修改并运行 pytest，再通过 26 个独立合同场景。

提交后崩溃用例恢复成功且业务写入为 1；证据丢失用例进入 NEEDS_REVIEW。后者属于正确安全停止，不计为恢复成功。

5/5 正常通过的 Wilson 95% 区间约为 [0.566, 1.000]；0/5 攻击成功的区间约为 [0.000, 0.434]。样本量不足以支持生产安全或广泛泛化结论，当前没有保留集和 Pass³ 成绩。

## 适配修正和证据

首次真实批次的正常任务为 4/5，另有一个攻击用例证据未知，原因是原适配器拒绝模型批量提出工具调用。失败报告已保留。现改为最多 4 个提议排队，每个动作单独消耗步数、校验、授权和审计；审批暂停停止后续动作。修正后重新完整评测得到上述结果。由于实现与 prompt 均变化，且模型存在波动，不将单次前后差异当成优化的因果估计。
