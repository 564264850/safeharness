复用当前 checkout，不操作其他项目的数据库。SafeHarness PostgreSQL 使用独立容器与本地端口。真实模型继续使用 M3 的持久预算账本和 0.50 CNY 总上限，已占用约 0.104 CNY；大规模确定性验收不调用付费模型。

A.I.G 扫描结果是候选证据。使用只含合成 canary 的隔离负对照验证扫描链路，生产式入口仍经过统一 Gateway，不能为获得发现而关闭真实入口的权限。测试实例与独立问题族分别计数。
